# Contributing

Issues and PRs are welcome — especially real-stream test reports.

- **Bug reports:** include the command you ran, the clip id, and `~/.live-clipper/logs/<task>.log`.
  Never paste tokens or `accounts.json`.
- **New layouts or rules:** change the skill (`skills/*/SKILL.md`) and the code together, and say
  which real clip you tested on.
- **Keep the rules:** PRs that bypass the approval gate, remove streamer credit, or add generated
  footage of streamers won't be merged.
